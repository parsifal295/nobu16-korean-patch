# 노부나가의 야망 신생 PK 한글 패치

Steam 일본어판 「신장의 야망·신생 with 파워업키트」 1.1.7용 비공식 한국어 패치입니다. 게임 언어를 **일본어(Japanese)**로 설정해 주세요.

**[v1.01 다운로드](https://github.com/parsifal295/nobu16-korean-patch/releases/tag/v1.01)** · [변경 내용](RELEASE_NOTES_v1.01_KO.md) · [설치 설명서](release_templates/v1.01/README_KO.txt)

## v1.01 변경 내용

무장 이름과 성·지역 이름의 오역을 수정하고, 무장 목록·열전·이벤트 대사에서 같은 이름을 다르게 적은 부분을 맞췄습니다. 와키자카 야스모토, 마쓰, 다카노야마 미치쓰구 등의 인명과 도시마·오사카·스이바라 등의 지명을 교정했습니다.

글꼴 A/B에 같은 수정이 적용되며, 이전 버전의 번역·이미지 수정과 설치 오류 수정을 모두 포함한 누적 패치입니다.

## 다운로드와 설치

설치 파일은 `NOBU16_PK_Korean_Patch_Steam_1.1.7_v1.01.zip`입니다. `Source code (zip)`과 `Source code (tar.gz)`는 설치용 파일이 아닙니다.

**이전 패치가 있다면 기존 패처에서 `2. 원본으로 복구`를 먼저 완료한 뒤 업데이트해 주세요.** 미리 받은 v1.01을 사용 중인 경우에도 같은 순서로 진행합니다. 복구 후에는 글꼴·이름 쓰기 방향·컨트롤러 지원을 다시 선택해야 합니다. `KR_PATCH_BACKUP` 폴더는 삭제하거나 옮기지 마세요.

v1.00 설치에 성공했던 경우에는 원본 복구 후 Steam의 `속성 → 설치된 파일 → 게임 파일 무결성 검사`도 진행해 주세요. v1.00 설치가 ‘원본 파일 검사 실패’로 중단됐고 이전 패치도 적용되어 있지 않다면 새 ZIP을 덮어쓴 뒤 바로 적용하면 됩니다.

1. 게임 언어가 일본어이고 버전이 1.1.7인지 확인한 뒤 게임과 런처를 종료합니다.
2. 이전 패치가 있다면 위 안내에 따라 원본으로 복구합니다. 복구가 실패하면 Steam의 게임 파일 무결성 검사를 진행해 주세요. 처음 설치한다면 이 단계는 건너뜁니다.
3. Steam에서 게임을 오른쪽 클릭하고 `관리 → 로컬 파일 탐색`을 선택합니다.
4. `NOBU16PK.exe`가 있는 폴더에 ZIP의 파일을 모두 풀고 덮어씁니다. `N16KoreanPatcher.exe`와 `NOBU16PK.exe`가 같은 폴더에 있어야 합니다. ZIP 안에서 패처를 실행하거나 별도 하위 폴더에 풀면 안 됩니다.
5. `N16KoreanPatcher.exe`에서 `1. 패치 설정 후 적용`을 선택합니다. 이름 쓰기 방향, 컨트롤러 지원 여부, 글꼴을 고른 뒤 적용을 마칠 때까지 기다립니다.
6. `3. 현재 설치 상태 확인`에서 `v1.01 적용 완료`를 확인합니다.

## 설정과 게임 실행

- 이름 쓰기 방향: 세로형 / 가로형
- 컨트롤러: 사용 안 함 / 실험적 지원
- 글꼴 A: SeoulHangang ExtraBold
- 글꼴 B: 그리운 경찰감성체

일반 설정은 평소처럼 Steam에서 실행합니다. 실험적 컨트롤러 지원을 선택했다면 컨트롤러를 먼저 연결하고 `NOBU16PK_XINPUT.exe`로 실행해 주세요.

설정을 바꾸려면 게임과 런처를 종료하고 패처의 `2. 원본으로 복구`를 실행한 뒤, `1. 패치 설정 후 적용`에서 다시 선택합니다.

Steam Input 설정, Steam Deck 설치와 문제 해결 방법은 [설치 설명서](release_templates/v1.01/README_KO.txt)에 있습니다. 같은 설명서가 ZIP에도 들어 있습니다.

## 참고 사항과 오류 제보

- 일부 이름은 저장 파일에 남아 있어 업데이트해도 기존 저장에서는 예전 표기가 보일 수 있습니다. 이전 버전에서 수정한 이이오 성씨도 새로 시작한 게임에 적용됩니다.
- 해상도를 바꾼 뒤 이미지가 이전 상태로 보이면 게임을 완전히 종료하고 다시 실행해 주세요.
- 전투 시작 때 불꽃과 함께 나오는 `開戦` 글자와 도움말의 게임화면 캡처에는 일본어가 남아 있습니다. 제품·회사 로고와 저작권 표기는 그대로입니다.
- 일부 화면에서 성과 이름이 붙어 보이는 문제는 남아 있습니다.
- 전법 이미지의 ‘톤보키리’와 게임 내 활자 이름 ‘돈보키리’는 의도한 표기 차이입니다.

이름이 잘못 나오거나 글자가 잘리면 [Issues](https://github.com/parsifal295/nobu16-korean-patch/issues)에 해당 이름과 화면, 해상도를 알려 주세요. 설치 오류가 발생했다면 `KR_PATCH_LOGS`의 로그 파일도 함께 보내 주세요.
