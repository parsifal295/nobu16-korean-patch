# 노부나가의 야망 신생 PK 한글 패치

Steam 일본어판 「신장의 야망·신생 with 파워업키트」 1.1.7용 비공식 한국어 패치입니다. 게임 언어를 **일본어(Japanese)**로 설정해 주세요.

## v1.00.1 핫픽스

`SCENARIO_PK/scedaPK13.n16`에서 ‘원본 파일 검사 실패’가 나오며 v1.00 설치가 중단되는 문제를 수정했습니다. 글꼴 A/B 모두 수정했으며, v1.00의 번역과 수정 사항을 모두 포함합니다.

**v1.00 설치에 성공했다면 기존 패처로 원본 복구를 마친 뒤 Steam의 게임 파일 무결성 검사도 진행하고 업데이트해 주세요.** 위 오류로 설치가 중단됐고 이전 패치도 적용되어 있지 않다면, 새 ZIP을 덮어쓴 뒤 바로 적용하면 됩니다.

[v1.00.1 릴리즈 노트](RELEASE_NOTES_v1.00.1_KO.md) · [v1.00.1 다운로드](https://github.com/parsifal295/nobu16-korean-patch/releases/tag/v1.00.1)

## v1.00 변경 내용

인명·지명 표기를 바로잡고, 글자 이미지에 남은 푸른색과 일부 전법 효과를 다듬었습니다. 이전 버전의 번역과 수정 사항을 모두 포함한 누적 패치입니다.

- 하루우지·도요우지·도모오키 등 일부 무장 이름을 교정하고, 같은 인물의 이름이 화면이나 대사에서 다르게 나오던 부분을 맞췄습니다.
- 자동으로 생성되는 일부 이름과 시로우사기·고우미·미노오 등 지명 표기를 수정했습니다.
- 수명·파·출분·중지·실패·달성·가입·승진 등의 글자에 남은 푸른색을 제거했습니다.
- 달성 도장의 붉은 빛을 복원하고, ‘지혜의 한발’ 발동 효과를 다듬었습니다.

글꼴 A/B 어느 쪽을 선택해도 같은 수정이 적용됩니다. 이이오 성씨가 이노로 나오던 두 무장의 이름도 고쳤으며, **이 성씨 수정은 새로 시작한 게임에 적용됩니다.** 기존 저장 파일은 바뀌지 않습니다.

자세한 내용은 [v1.00 릴리즈 노트](RELEASE_NOTES_v1.00_KO.md)를 확인해 주세요.

## 다운로드와 설치

다운로드는 [v1.00.1 다운로드](https://github.com/parsifal295/nobu16-korean-patch/releases/tag/v1.00.1)에서 제공하며, 설치 파일 이름은 `NOBU16_PK_Korean_Patch_Steam_1.1.7_v1.00.1.zip`입니다. `Source code (zip)`과 `Source code (tar.gz)`는 설치용 파일이 아닙니다.

1. 게임 언어가 일본어이고 게임 버전이 1.1.7인지 확인한 뒤, 게임과 런처를 종료합니다.
2. 이전 패치가 있다면 **기존 패처에서 `2. 원본으로 복구`를 먼저 실행**하고 패처를 닫습니다. **v1.00 설치에 성공했다면 복구 후 Steam의 `속성 → 설치된 파일 → 게임 파일 무결성 검사`도 진행해 주세요.** 복구가 실패한 경우에도 무결성 검사를 진행합니다. 처음 설치한다면 이 단계는 건너뜁니다.
3. Steam에서 게임을 오른쪽 클릭하고 `관리 → 로컬 파일 탐색`을 선택합니다.
4. `NOBU16PK.exe`가 있는 폴더에 ZIP의 파일을 모두 풀고 덮어씁니다. `N16KoreanPatcher.exe`와 `NOBU16PK.exe`가 같은 폴더에 있어야 합니다. ZIP 안에서 패처를 실행하거나 별도 하위 폴더에 풀면 안 됩니다.
5. `N16KoreanPatcher.exe`를 실행하고 `1. 패치 설정 후 적용`을 선택합니다. 이름 쓰기 방향, 컨트롤러 지원 여부, 글꼴을 고른 뒤 적용이 끝날 때까지 기다립니다.
6. `3. 현재 설치 상태 확인`에서 `v1.00.1 적용 완료`를 확인합니다.

**`KR_PATCH_BACKUP` 폴더는 설정 변경과 원본 복구에 필요합니다. 삭제하거나 옮기지 마세요.**

## 설정과 게임 실행

- 이름 쓰기 방향: 세로형 / 가로형
- 컨트롤러: 사용 안 함 / 실험적 지원
- 글꼴 A: SeoulHangang ExtraBold
- 글꼴 B: 그리운 경찰감성체

일반 설정은 평소처럼 Steam에서 실행합니다. 실험적 컨트롤러 지원을 선택했다면 컨트롤러를 먼저 연결하고 `NOBU16PK_XINPUT.exe`로 실행해 주세요.

설정을 바꾸려면 게임과 런처를 종료하고 패처의 `2. 원본으로 복구`를 실행한 뒤, `1. 패치 설정 후 적용`에서 다시 선택합니다.

Steam Input 설정, Steam Deck 설치와 문제 해결 방법은 [설치 설명서](release_templates/v1.00.1/README_KO.txt)에 있습니다. 같은 설명서가 ZIP에도 들어 있습니다.

## 참고 사항과 오류 제보

- 해상도를 바꾼 뒤 이미지가 이전 상태로 보이면 게임을 완전히 종료하고 다시 실행해 주세요.
- 전투 시작 때 불꽃과 함께 나오는 `開戦` 글자와 도움말의 게임화면 캡처에는 일본어가 남아 있습니다. 제품·회사 로고와 저작권 표기는 그대로입니다.
- 일부 화면에서 성과 이름이 붙어 보이는 문제는 남아 있습니다.
- 전법 이미지의 ‘톤보키리’와 게임 내 활자 이름 ‘돈보키리’는 의도한 표기 차이입니다.

글자가 잘리거나 번역이 어색하면 [Issues](https://github.com/parsifal295/nobu16-korean-patch/issues)에 해당 화면과 해상도를 알려 주세요. 설치 오류가 발생했다면 `KR_PATCH_LOGS`의 로그 파일도 함께 보내 주세요.
