NOBU16 PK 한국어 패치 v0.95.0
================================

Windows 설치 방법
-----------------
이 패치는 별도의 설치 프로그램을 쓰지 않습니다. 배포 ZIP의 파일을 게임 폴더에
모두 풀고 그 폴더에서 패처를 실행하면 됩니다. 처음 설치할 때나 이전 버전에서 업데이트할 때 모두 아래 순서대로 진행하십시오.

1. Steam에서 게임 언어가 일본어로 설정되어 있는지 확인하고, 게임을 최신
   버전으로 업데이트합니다.
2. 실행 중인 게임과 런처, 패처를 모두 종료합니다.
3. 이전 한국어 패치가 적용되어 있다면 기존 패처를 먼저 실행해 메뉴
   `2. 원본으로 복구`를 완료합니다. 처음 설치한다면 이 단계는
   건너뜁니다.
4. 원본 복구가 되지 않으면 Steam에서 게임을 오른쪽 클릭한 뒤
   `속성 > 설치된 파일 > 게임 파일 무결성 검사`를 실행합니다. 검사가 끝나면
   설치를 계속합니다.
5. Steam 라이브러리에서 게임을 오른쪽 클릭하고 `관리 > 로컬 파일 탐색`을
   선택합니다.
6. 열린 폴더에 `NOBU16PK.exe`가 있는지 확인합니다. 이 폴더가 패치를 설치할
   게임 폴더입니다.
7. 배포 ZIP을 열고 안에 든 파일을 모두 게임 폴더에 압축 해제합니다. ZIP
   안에서 패처를 바로 실행하거나 게임 폴더 아래에 별도의 하위 폴더를 만들어
   그 안에 압축을 풀면 안 됩니다.
8. 같은 이름의 파일을 덮어쓸지 묻는 창이 나오면 모두 덮어씁니다. 압축 해제가
   끝나면 `N16KoreanPatcher.exe`와 `NOBU16PK.exe`가 같은 폴더에 있어야 합니다.
9. 게임 폴더의 `N16KoreanPatcher.exe`를 실행하고 메뉴
   `1. 패치 설정 후 적용`을 선택합니다.
10. 안내에 따라 다음 세 가지를 선택합니다.
    - 이름 쓰기 방향: 기존 세로형 또는 가로형
    - 컨트롤러 지원: 사용 안 함 또는 실험적 지원 사용
    - 글꼴: `A. SeoulHangang ExtraBold` 또는 `B. 그리운 경찰감성체`
11. 선택한 설정을 확인하고 패치를 적용합니다. 완료 메시지가 나올 때까지 패처
    창을 닫지 마십시오.
12. 메인 메뉴로 돌아오면 메뉴 `3. 현재 설치 상태 확인`을 선택합니다.
    `v0.95.0 적용 완료`가 표시되면 설치가 끝났습니다.

패치를 적용한 뒤에는 게임 폴더의 `KR_PATCH_BACKUP` 폴더를 삭제하거나 옮기지
마십시오. 설정을 바꾸거나 원본으로 복구할 때 필요합니다.

지원 대상
---------
- Steam 일본어판 「신장의 야망·신생 with 파워업키트」 1.1.7
- 다른 언어판, 기본판 전용 실행 파일, 그 밖의 게임 버전에는 적용되지 않습니다.

v0.95.0 주요 변경
-----------------
다음 이미지를 저해상도와 고해상도에서 모두 한국어로 교체했습니다.

- 기본판과 PK의 역사 전법 타이틀 카드 46종과 강조·발동 효과
- 역사 전투 선택 화면의 결과 문구와 전투명
- 게임 시작 시 표시되는 주의 안내문
- 합전의 승패 결과와 `다이묘 전사`, `적 전 부대 격파`,
  `아군 전 부대 괴멸`, `기마 돌격`, `철포 사격` 등의 연출 문구
- 합전 요충지 연출의 `낙석`, `고무`, `다리파괴` 표기
- 일반 UI의 `군 제압`, `잇키 진압`, 처분 명령, 달성·실패 표시,
  구매·승진 상태 배지

번역과 표기도 함께 다듬었습니다.

- 기본판과 PK의 역사 이벤트에서 고정된 인물명이나 성씨 뒤에 잘못 표시되던
  조사를 바로잡았습니다.
- 성 주변 지역명 전체를 일본어판 독음과 대조해, 일반 단어로 잘못 번역되거나
  독음이 틀린 지명을 교정했습니다.
- 1582년 시나리오 제목 `덧없는 꿈처럼`을 원전 구절에 맞춰
  `몽환과 같이`로 바로잡았습니다.
- 가신 신분 안내와 UI에서 혼용되던 `조두`를 `조장`으로 통일했습니다.
- 일부 무장 이름의 `모토지` 표기를 `모토우지`로 바로잡고, 특성
  `야샤미노`의 이름과 독음을 통일했습니다.

게임 실행 방법
--------------
- 컨트롤러 지원을 사용하지 않았다면 평소처럼 Steam에서 게임을 실행합니다.
- 실험적 컨트롤러 지원을 선택했다면 게임 폴더의 `NOBU16PK_XINPUT.exe`를 실행합니다.
- XInput 실행본에 Steam Input을 사용하려면 Steam의
  `게임 추가 > 비 Steam 게임 추가`에서 `NOBU16PK_XINPUT.exe`를 등록한 뒤,
  해당 항목의 컨트롤러 설정에서 Steam Input을 켭니다.
- 컨트롤러는 게임을 실행하기 전에 연결하십시오.

설정 변경 및 원본 복구
----------------------
1. 게임과 런처를 완전히 종료합니다.
2. `N16KoreanPatcher.exe`를 실행합니다.
3. 화면 방향, 컨트롤러 또는 글꼴을 바꾸려면 먼저 메뉴 `2`로 원본 복구를 완료합니다.
4. 메인 메뉴로 돌아와 메뉴 `1`을 선택하고 원하는 설정으로 다시 적용합니다.
5. 한국어 패치를 제거하려는 경우에는 메뉴 `2`로 원본 복구를 마치면 됩니다.

Steam Deck 설치
---------------
1. Steam Deck을 데스크톱 모드로 전환합니다.
2. Steam 라이브러리에서 게임의 로컬 파일 폴더를 엽니다.
3. ZIP 안의 모든 파일을 `steamapps/common/NOBU16` 폴더에 압축 해제합니다.
4. Proton 또는 Wine으로 `N16KoreanPatcher.exe`를 실행합니다.
5. PC와 같은 순서로 메뉴 `1`에서 원하는 설정을 적용합니다. Steam Deck용 실행 파일은 함께 적용됩니다.
6. 완료 후 게이밍 모드로 돌아가 Steam에서 평소처럼 게임을 실행합니다.

패처 메뉴
---------
- `1`: 설정을 선택한 뒤 패치 적용
- `2`: 패치 적용 전 원본으로 복구
- `3`: 현재 설치 상태 확인
- `0`: 패처 종료

문제 해결
---------
- `NOBU16PK.exe가 있는 게임 폴더가 아닙니다`라고 나오면 패처와 ZIP의 다른
  파일을 `NOBU16PK.exe`가 있는 폴더로 옮긴 뒤 다시 실행하십시오.
- 패처 창이 바로 닫히거나 필요한 파일이 없다고 나오면 ZIP 안에서 패처를
  실행하지 않았는지 확인하고 ZIP 전체를 게임 폴더에 다시 압축 해제하십시오.
- 지원하지 않는 버전이라는 안내가 나오면 Steam에서 게임 언어를 일본어로
  설정하고 최신 1.1.7 버전인지 확인한 뒤 게임 파일 무결성 검사를 실행하십시오.
- Steam 업데이트나 게임 파일 무결성 검사 후에는 패치 일부가 원본으로 돌아갈
  수 있습니다. 메뉴 `3`으로 상태를 확인하고 필요하면 원본으로 복구한 뒤 다시
  적용하십시오.
- 해상도를 바꾼 뒤 메뉴·버튼·타이틀 이미지가 이전 상태로 보이면 게임을
  완전히 종료한 다음 다시 실행하십시오.
- 오류를 제보할 때는 게임 폴더의 `KR_PATCH_LOGS`에 있는 로그 파일을 함께
  보내 주십시오.

권리 고지
---------
게임 실행 파일과 원본 데이터의 권리는 KOEI TECMO GAMES 및 각 권리자에게
있습니다. 이 배포물은 원본 게임 파일을 포함하지 않습니다.
