신생 PK 한국어 패치 v1.00.1
========================

Steam 일본어판 「신장의 야망·신생 with 파워업키트」 1.1.7용 비공식 한국어
패치입니다. 게임 언어를 일본어(Japanese)로 설정해 주세요.
다른 언어판, 기본판 전용 실행 파일과 다른 게임 버전에는 적용되지 않습니다.

v1.00.1 설치 오류 수정
-----------------------
v1.00 설치 중 SCENARIO_PK/scedaPK13.n16에서 ‘원본 파일 검사 실패’가 나오며
적용이 중단되는 문제를 수정했습니다. 글꼴 A/B 모두 해당합니다.
게임 내 번역·이미지·기능은 v1.00과 같으며, 이전 수정 사항을 모두 포함합니다.

v1.00에서 위 오류로 설치가 중단됐고 이전 패치도 적용되어 있지 않다면,
새 ZIP을 게임 폴더에 덮어쓴 뒤 바로 적용하면 됩니다.
v1.00 설치에 성공했다면 기존 패처로 원본 복구를 마친 뒤 Steam의
‘속성 → 설치된 파일 → 게임 파일 무결성 검사’도 진행하고 업데이트해 주세요.

v1.00에 포함된 변경 내용
-----------------------
인명·지명 표기를 바로잡고, 글자 이미지에 남은 푸른색과 일부 전법 효과를
다듬었습니다. 이전 버전의 번역과 수정 사항을 모두 포함한 누적 패치입니다.

- 하루우지·도요우지·도모오키 등 일부 무장 이름을 교정하고, 같은 인물의 이름이
  화면이나 대사에서 다르게 나오던 부분을 맞췄습니다.
- 자동으로 생성되는 일부 이름과 시로우사기·고우미·미노오 등 지명 표기를
  수정했습니다.
- 수명·파·출분·처단·전사·중지·실패·달성·가입·승진 등의 글자에 남은 푸른색을
  제거했습니다. 달성 도장의 붉은 빛과 ‘지혜의 한발’ 발동 효과도 다듬었습니다.

글꼴 A/B 어느 쪽을 선택해도 같은 수정이 적용됩니다. 이미지 수정은 저해상도와
고해상도에 모두 포함됩니다. 자세한 변경 내용은 함께 들어 있는
STATIC_PATCH_CHANGELOG_KO.md를 확인해 주세요.

이이오 성씨가 이노로 나오던 두 무장의 이름도 수정했습니다.
이 성씨 수정은 새로 시작한 게임에 적용됩니다. 기존 저장 파일은 바뀌지 않습니다.

Windows 설치와 업데이트
------------------------
1. 게임 언어가 일본어이고 게임 버전이 1.1.7인지 확인한 뒤, 게임과 런처를
   종료합니다.
2. 이전 패치가 있다면 기존 N16KoreanPatcher.exe를 실행해 ‘2. 원본으로 복구’를
   먼저 완료하고 패처를 닫습니다. 처음 설치한다면 이 단계는 건너뜁니다.
   복구가 실패하면 Steam에서 게임을 오른쪽 클릭하고
   ‘속성 → 설치된 파일 → 게임 파일 무결성 검사’를 진행해 주세요.
3. Steam에서 게임을 오른쪽 클릭하고 ‘관리 → 로컬 파일 탐색’을 선택합니다.
   열린 폴더에 NOBU16PK.exe가 있는지 확인합니다.
4. ZIP의 파일을 모두 그 폴더에 풀고 덮어씁니다. N16KoreanPatcher.exe와
   NOBU16PK.exe가 같은 폴더에 있어야 합니다. ZIP 안에서 패처를 바로 실행하거나
   별도 하위 폴더에 풀면 안 됩니다.
5. N16KoreanPatcher.exe를 실행하고 ‘1. 패치 설정 후 적용’을 선택합니다.
   이름 쓰기 방향, 컨트롤러 지원 여부, 글꼴을 고른 뒤 ‘4. 위 설정으로 적용’을
   선택합니다. 완료 메시지가 나올 때까지 패처 창을 닫지 마세요.
6. ‘3. 현재 설치 상태 확인’에서 ‘v1.00.1 적용 완료’를 확인하면 설치가 끝납니다.

KR_PATCH_BACKUP 폴더는 설정 변경과 원본 복구에 필요합니다.
삭제하거나 옮기지 마세요.

설정 선택
---------
- 이름 쓰기 방향: 세로형 / 가로형
- 컨트롤러: 사용 안 함 / 실험적 지원
- 글꼴 A: SeoulHangang ExtraBold
- 글꼴 B: 그리운 경찰감성체

게임 실행
---------
컨트롤러 지원을 사용하지 않았다면 평소처럼 Steam에서 실행합니다.
실험적 컨트롤러 지원을 선택했다면 컨트롤러를 먼저 연결하고 게임 폴더의
NOBU16PK_XINPUT.exe로 실행해 주세요.

Steam Input을 사용할 때는 다음과 같이 설정합니다.
1. Steam의 ‘게임 추가 → 비 Steam 게임 추가’에서 NOBU16PK_XINPUT.exe를 등록합니다.
2. 등록한 항목의 컨트롤러 설정에서 Steam Input을 켭니다.
3. 컨트롤러를 연결한 뒤 등록한 항목으로 게임을 실행합니다.

설정 변경과 패치 제거
---------------------
게임과 런처를 종료한 뒤 N16KoreanPatcher.exe의 ‘2. 원본으로 복구’를 실행합니다.
설정을 바꾸려면 복구가 끝난 뒤 ‘1. 패치 설정 후 적용’에서 다시 선택해 주세요.
패치를 제거하려면 원본 복구를 마치면 됩니다.

Steam Deck 설치
---------------
1. 데스크톱 모드로 전환하고, Steam에서 게임 언어가 일본어이고 버전이 1.1.7인지
   확인합니다. 게임은 종료해 주세요.
2. 이전 패치가 있다면 기존 패처를 Proton 또는 Wine으로 실행해
   ‘2. 원본으로 복구’를 완료하고 닫습니다. 처음 설치한다면 건너뜁니다.
   복구가 실패하면 Steam의 게임 파일 무결성 검사를 진행해 주세요.
3. Steam에서 게임의 로컬 파일 폴더를 엽니다. ZIP의 파일을 모두
   steamapps/common/NOBU16 폴더에 풀고 덮어씁니다.
4. Proton 또는 Wine으로 N16KoreanPatcher.exe를 실행하고,
   ‘1. 패치 설정 후 적용’에서 원하는 설정을 고릅니다.
   Steam Deck용 패치도 함께 적용됩니다.
5. ‘3. 현재 설치 상태 확인’에서 ‘v1.00.1 적용 완료’를 확인합니다.
6. 게이밍 모드로 돌아가 Steam에서 평소처럼 게임을 실행합니다.
   실험적 컨트롤러 지원으로 실행하려면 위 ‘게임 실행’ 안내를 따라 주세요.

문제가 생겼을 때
----------------
- 게임 폴더가 아니라는 안내가 나오거나 필요한 파일이 없다고 나오면,
  ZIP 전체를 NOBU16PK.exe가 있는 폴더에 풀었는지 확인해 주세요.
- 지원하지 않는 버전이라는 안내가 나오면 게임 언어가 일본어이고 버전이
  1.1.7인지 확인한 뒤 Steam의 게임 파일 무결성 검사를 진행해 주세요.
- Steam 업데이트나 게임 파일 무결성 검사 후에는 패치 일부가 원본으로 돌아갈
  수 있습니다. 패처의 ‘3. 현재 설치 상태 확인’으로 확인하고, 필요하면 원본으로
  복구한 뒤 다시 적용해 주세요.
- 해상도를 바꾼 뒤 이미지가 이전 상태로 보이면 게임을 완전히 종료하고
  다시 실행해 주세요.
- 글자가 잘리거나 번역이 어색하면 해당 화면과 해상도를 알려 주세요.
  설치 오류를 제보할 때는 KR_PATCH_LOGS의 로그 파일도 함께 보내 주세요.
