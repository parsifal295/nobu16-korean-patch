# 1582년 시나리오 제목 교정

`夢幻の如く`은 행복무용(幸若舞) 「敦盛」의 `夢幻の如くなり`를 인용한 제목이다. 의미만 풀어 쓴 `덧없는 꿈처럼`을 사용하지 않고, 인용 형식을 보존한 `몽환과 같이`로 통일한다.

공식판 대조 결과는 일본어 `夢幻の如く`, 영어 `Like A Dream`, 중국어 간체 `宛如梦幻`, 중국어 번체 `如夢似幻`이다.

- PK판 `MSG_PK/JP/msgdata.bin`: ID 15118
