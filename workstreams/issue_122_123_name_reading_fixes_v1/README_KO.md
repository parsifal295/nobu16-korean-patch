# 이슈 122·123 이름 및 독음 교정

이 작업은 v0.95.0의 현재 메시지 바이너리를 기준으로 다음 네 문자열만 수정한다.

- 공통 이름부 `모토지` → `모토우지`
- `하타야마 모토지` → `하타야마 모토우지`
- `모리 모토지` → `모리 모토우지`
- 특성 독음 `야차미농` → `야샤미노`

일본어 원본 좌표와 해시를 함께 검사한다. 이미 올바른 `깃카와 모토우지`,
`strdata`의 공통 이름부, 특성명 `야샤미노`, 관련 합전 대사 세 곳은 읽기 전용
기준점으로 확인하며 수정하지 않는다.

```powershell
python workstreams/issue_122_123_name_reading_fixes_v1/build_issue_122_123_name_reading_fixes_v1.py `
  --input-root <v0.95 target root> `
  --jp-reference-root <Steam 1.1.7 Japanese stock root> `
  --output-root <empty scratch output>
```

빌더는 입력과 일본어 원본의 크기·SHA-256, 좌표별 원문 해시, 압축 방식까지
고정한다. 결과를 다시 파싱해 변경 좌표가 정확히 네 곳인지 확인하고 Steam 설치
폴더로 직접 출력하는 것도 거부한다.
