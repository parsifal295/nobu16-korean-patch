# 출진 화면 조사 보정

출진 부대 확인 화면에서 동적 가문·세력명 뒤에 `와의 전투`가 붙어 `가문와의 전투`로 표시되는 문제를 수정합니다.

- Base `MSG/JP/msggame.bin`: 관련 분기 5개
- PK `MSG_PK/JP/msggame.bin`: 관련 분기 2개
- 변경: `와의 전투` → `과의 전투`
- 유지: 동적 명칭 토큰, 후속 문장, 개행, 제어 코드, 레코드 크기

표시되는 앞말은 `가문` 또는 `세력`이므로 두 경우 모두 `과의`가 맞습니다. 입력 파일과 대상 레코드 해시를 고정하고, 두 번의 빌드 결과가 동일한지 및 다른 레코드가 바뀌지 않았는지를 테스트합니다.
