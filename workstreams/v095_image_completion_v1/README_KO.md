# v0.95 이미지 완성·통합 검증 기록

2026-09-05 기준으로 사용자 승인 이미지를 확정하고 글꼴 A/B 패키지와 승인된
Steam 설치본에 반영했다. 이 폴더는 상용 원본과 중간 이미지를 제외한 공개 기록이다.

최종 공개 ZIP은 설치 안내와 변경 설명을 보강한
[v0.95 배포 명세](../../release_templates/v0.95/release_manifest.v1.json)를 따른다.
이 폴더의 검증 기록은 문서 보강 전 승인본의 이력으로 보존한다. 공개 ZIP에서는
문서 두 개와 구성 체크섬만 바뀌었으며 게임 리소스·패처 등 바이너리 10개는 같다.

## 전법 타이틀

기본판 35종과 PK 11종, 총 46종의 승인 베이스에서 저·고해상도와 일반·강조·발동
상태를 만들어 276개 배치를 완성했다. 이미지와 세 아카이브를 각각 독립적으로
두 번 빌드해 같은 결과를 확인했다. 전법 밖 아카이브 항목은 보존했다.

[전법 목록](tactic_titles.v1.json)에 게임 내 메시지 ID, 활자·이미지 표기와 승인
베이스 해시를 기록했다. 45종은 활자와 이미지가 같고, 한 종만 사용자 승인에 따라
활자 **돈보키리**, 이미지 **톤보키리**로 유지한다. 이 예외를 자동으로 통일하면
안 된다. 근거는 [표기 예외 계약](title_text_image_exceptions.v3.json)에 있다.

## 검증 범위

[통합 검증 기록](validation.v1.json)에 다음 결과를 남겼다.

- 최종 설치 파일에서 이슈 #122·#123 이름과 독음, #124 지명 2,014쌍,
  #125 직급 35곳, 전법명 46종을 재확인했다.
- 글꼴 A/B 번들의 격리 적용·검증·원본 복구를 통과했다.
- 최종 ZIP은 13개 파일이며 새로 풀어 구성 파일 체크섬 12개를 확인했다.
- Steam 리소스 147개, 설치 관리 파일 151개와 패키지 체크섬 12개를 확인했다.
  글꼴 B·가로형 XInput·Steam Deck 구성을 유지했고 원본 백업도 확인했다.
- 최종 적용 후 실게임 화면 검증은 **미수행**이다. 선택 해상도는 기록하지
  않았으며 적용 후 전체 프로세스 재시작도 수행하지 않았다. 향후 이미지 QA는
  해상도를 기록하고 게임을 완전히 종료·재실행한 뒤 판정해야 한다.

제품 패처 소스, 서명·패키징·배포 스크립트, 상용 원본, 중간 이미지와 비밀키는
공개하지 않는다. GitHub PR 병합과 배포 ZIP의 릴리스 업로드는 별개이며,
이 검증 기록을 작성할 때 v0.95.0 GitHub 릴리스는 아직 게시하지 않았다.
