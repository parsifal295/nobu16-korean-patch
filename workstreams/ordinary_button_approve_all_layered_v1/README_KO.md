# `전체승인` 일반 버튼 레이어 재작업 v1

## 확정 결과

`全承認` 버튼을 합의한 B 파이프라인으로 저·고해상도 각각 6상태씩
재구축한다. 한국어 표기는 공백 없는 **`전체승인`**으로 고정한다.

- 글꼴: B, `SeoulHangang ExtraBold`
- 크기: `전체승인` 긴 표기 전용 Compact, 저해상도 잉크 높이 26px /
  고해상도 52px
- 오버샘플: 저해상도 8× / 고해상도 4×
- 자간: 파이프라인 기본값 `standard`, `-0.035em`
- 장평: 가로 80% (`aspect_scale_x = 0.80`)
- 생성형 채움·인페인팅: 없음

장평 비교 시트의 열은 `순정 → 클린 몸체 → 84% → 82% → 80%`이다.
`전체승인`은 긴 표기 때문에 사용자가 명시적으로 요청한 예외로 Compact와
가로 80%를 함께 적용한다. 글자 형태가 뭉개지지 않도록 자간은 파이프라인
기본값으로 되돌린다. 상태별 재질과 체크 아이콘 위치는 바꾸지 않는다.
순정 체크 코어와 `全` 코어 사이의 최단거리를 네이티브 해상도별로
측정하고, 새 `전`의 흰색 상태 잉크도 그 거리와 0.75px 이내로
일치시킨다.

첫 28/56px·90% 재빌드는 저해상도 우측 장식선과의 시각 여백이
부족했다. 장평을 80%로 줄인 뒤에도 종전 중심을 유지하면 체크와 `전`
사이가 과도하게 벌어지므로, 순정 간격을 기준으로 저해상도 13px,
고해상도 17px 왼쪽으로 이동했다. 최종 글자 중심은 저해상도
`(117, 41)`, 고해상도 `(227, 76)`이며, 모든 상태의 최종 글자 경계는
저해상도 `x=74..178`, 고해상도 `x=140..338` 내부 레인을 벗어나면
빌드를 중단한다.

체크 보호영역은 레이아웃 여백이 아니라 원본 픽셀 복원용 마스크다.
따라서 실제 체크 외곽선의 안티앨리어싱 여유만 포함하도록 코어를
저해상도 3px(커널 7), 고해상도 6px(커널 13) 확장한다. 이 마스크와
새 글자층의 교차는 0이어야 하고, 합성 뒤 보호 픽셀은 순정과 완전히
같아야 한다.

## 좌표 정정

초기 탐색에서 고해상도 368×160 좌표를 단순히 절반으로 나눈 184×80
영역은 잘못된 추정이었다. 그 영역은 실제 저해상도 버튼 아래쪽을 잘랐다.

실제 저해상도 버튼은 알파 컴포넌트와 192px 패킹 간격으로 확인한
**192×88 네이티브 셀**이다. 정식 빌더는 다음 순서로 기록한다.

`white → cyan → blue → disabled → cyan_alt → disabled_alt`

- 저해상도: `RES_JP_PK/res_lang_exp_pk.bin`, `/4` → `/0`, 리소스
  `870`, 텍스처 `1`, 2048×512 BC7
- 고해상도: `RES_JP_PK_PORT/res_lang_pk_port2.bin`, `/2` → `/0`,
  리소스 `870`, 텍스처 `1`, 4096×1024 BC7

저해상도 좌표는 고해상도에서 추정하지 않고 각 순정 아틀라스의 실제
컴포넌트를 독립 검출했다.

## 레이어 파이프라인

1. JP·EN·SC·TC 순정 아카이브를 크기와 SHA-256으로 고정한다.
2. 6상태의 색 전이로 전경을 찾고, 체크 아이콘과 원문 글자 코어를 연결
   요소로 분리한다.
3. 같은 JP 아틀라스의 짧은 `姫` 버튼을 동일 재질의 1순위 공여본으로
   사용한다. 같은 좌표가 글자에 가려진 픽셀만 같은 행의 가장 가까운 실제
   공여 픽셀을 복사한다.
4. 체크 아이콘 보호 마스크를 순정 JP 픽셀로 복원하고 바이트 차이 0을
   확인한다.
5. `전체승인` 글자층을 네이티브 해상도별로 따로 래스터화한다.
6. 실제 픽셀 변화와 겹치는 4×4 BC7 블록만 고정 인코더로 교체한다.
7. 논리 셀 밖·선택 블록 밖 변화 0과 결정론적 재빌드를 검사한다.
