# 이벤트 고정 인물 조사 데이터화 v1

이 작업은 이벤트 대사의 고정 인물 토큰 뒤 조사를 실행 파일 수정 없이 이벤트 데이터에 확정해 넣는다.

## 범위

- `[bN]`: 인물의 전체 이름
- `[bmN]`: 인물의 이름
- `[bsN]`: 인물의 성씨
- Base 316건, PK 293건, 합계 609건
- 실제로 잘못 선택되어 글자가 바뀌는 경계는 Base 61건, PK 80건이다.
- 이미 맞는 468건도 같은 규칙으로 검사해 회귀를 막는다.

통일 엔딩의 `[bu]`, `[bum]`, `[cuh]` 가변 토큰 18건은 사용자의 지시에 따라 문장과 조사를 원문 그대로 보존한다. `%s`를 사용하는 다른 가변 문장과 이벤트 범위 밖의 문자열도 이 작업에서 수정하지 않는다.

## 판정 방식

이벤트 이름 표의 동일 인물 ID에서 실제 한국어 출력값을 가져온다. 전체 이름·이름·성씨 중 토큰이 지정한 부분의 마지막 한글 음절을 보고 받침 유무를 판정한다. `으로/로`는 ㄹ 받침 예외도 적용한다.

`[bsN]가`는 두 뜻이 가능하다. 뒤에 별도의 색상 종료 태그가 붙는 `성씨+가(家)`는 가문명 일부이므로 제외하고, 일반 문장이 바로 이어지는 `가`만 주격 조사로 처리한다.

## 안전 조건

- 두 입력 파일의 크기와 SHA-256을 고정한다.
- 검토된 609개 경계 좌표 전체의 서명을 고정한다.
- 통일 엔딩 18개 경계의 별도 서명을 고정하고 빌드 전후 동일성을 검사한다.
- 변경 대상이 아닌 모든 문자열 행은 완전히 동일해야 한다.
- PK 변경 행은 30px 런타임 기준으로 각 줄의 원본 G1N 폭, 환산 폭, 전각·반각 문자 수와 4줄 제한을 기록하고 912px 초과를 차단한다. Base 이벤트는 동일 위젯임이 입증되지 않았으므로 같은 수치를 기록하되 912px 기준을 합격 조건으로 강제하지 않는다.
- 빌더는 Steam 설치 경로에 직접 쓸 수 없다.

## 실행 예

```powershell
python workstreams/event_static_particles_v1/build_event_static_particles_v1.py `
  --input-root I:\Workspaces\NOBU16-Korean\scratch\release-v0941-force-label-20260820-01\generator-a\target `
  --output-root I:\Workspaces\NOBU16-Korean\scratch\event-static-particles-v1\candidate
```

출력 감사 JSON에는 609건 각각의 토큰, 실제 출력 이름, 기존 조사, 확정 조사와 변경 여부가 기록된다.
