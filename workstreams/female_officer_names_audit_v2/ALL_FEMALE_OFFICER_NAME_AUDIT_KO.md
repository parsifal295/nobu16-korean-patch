# 전체 여성 무장 이름 — 조합·표기 비교

## 범위와 판정 기준

정적 무장 테이블의 검토된 57명 선택값(`record + 0x4C`이 `09`, `0A`, `0B`)을 이용해
내장 역사 여성 무장을 전수 대조했다. 기존 21명 명단은 모두 이 집합에 포함된다.
이 선택값의 필드명 자체를 추정하지 않으며, 파일 레이아웃·레코드 ID·57명 전체 목록을
감사기가 고정 검증한다.

각 이름은 다음 두 축으로 분리했다.

1. **조합 정적 대조:** SC 원문의 모든 정확한 두-part 분해를 찾아, 승인된 11행
   `msgdata` 변경을 메모리에서만 적용한 한국어 component 결과와 직접 `msgev` 표시를
   비교한다. 이는 실제 런타임 레코드가 그 pair를 사용한다는 증거가 아니다.
2. **통용 표기 검토:** 직접 `msgev`의 현행 한국어 표기를 보존 기준으로 삼고, 일본어
   전사 일관성만 별도로 점검한다. `츠`/`쓰`처럼 이미 널리 혼용되는 표기는 자동 수정하지
   않는다. [국립국어원 일본어 외래어 표기법](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=326521)의 `つ → 쓰` 원칙은 엄격 전사의 기준일 뿐,
   개별 역사 인명의 관용 표기를 단독으로 뒤집는 근거는 아니다.

## 통용 표기 검토 결과

현행 직접 표기 57명 중, 엄격 전사와 충돌하거나 같은 프로젝트 안에서 표기가 갈리는 항목은
아래 4명뿐이다. 모두 **정책 검토**이며 자동 수정 후보가 아니다.

| `msgev` ID | 현행 직접 표기 | 엄격 전사 참고형 | 판정 |
|---:|---|---|---|
| 486 | 오호리 츠루 | 오호리 쓰루 | `츠/쓰` 표기 스타일 검토 |
| 567 | 오츠야노카타 | 오쓰야노가타 | 관용형과 엄격 전사 차이 |
| 1827 | 마츠 | 마쓰 | 마츠/마쓰 혼용. 마쓰히메와의 일관성 정책 필요 |
| 2005 | 무라마츠도노 | 무라마쓰도노 | 마쓰히메와 다른 `마츠/마쓰` 선택 |

따라서 현재 결론은 다음과 같다.

- 11행 `msgdata` 후보 외에 여성 무장 전체에 적용할 추가 component 치환은 없다.
- 직접 `msgev` 이름을 변경한다면 component가 아니라 **이 4개 표기 정책**을 먼저 정해야
  하며, 특히 `마츠`와 `마쓰` 중 어느 관용형을 프로젝트 표준으로 채택할지 결정이 필요하다.
- 그 정책을 정해도 component 조합 결과가 직접 이름과 다른 14명은 별도 레코드 매핑을
  확보하기 전까지 수정하지 않는다.
