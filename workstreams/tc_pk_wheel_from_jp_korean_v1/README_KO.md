# 번체중문 PK 휠 한국어 스프라이트 이식 v1

JP 경로에 적용된 한국어 PK 휠을 번체중문(TC) 저해상도·고해상도
아틀라스의 같은 의미 레코드로 이식한다.

- 저해상도: `RES_TC_PK/res_lang_pk.bin`, outer `/1`, resource `81`, texture `0`
- 고해상도: `RES_TC_PK_PORT/res_lang_pk_port2.bin`, outer `/3`, resource `81`, texture `0`
- 상세 휠 12종 × 6상태 = 72레코드
- 중앙 `광역` 1종 × 6상태 = 6레코드
- 활성 레코드 `0..77` 전체 교체
- 비문자용 꼬리 레코드 `78..81` 보존

JP 파일이나 아틀라스를 통째로 복사하지 않는다. 각 파일의 LINK/G1T 구조와
TC 좌표표는 보존하고, 디코드한 스프라이트만 대응 레코드에 넣는다.
고해상도 중앙 `광역`은 JP 셀(204×188)을 TC 셀(200×184)에
premultiplied-alpha Lanczos3 방식으로 축소한다.

실게임 판정은 1920×1080 선택 후 `NOBU16PK.exe`를 완전히 종료하고 다시
실행한 상태에서 수행해야 한다.
