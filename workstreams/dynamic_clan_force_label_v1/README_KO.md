# 동적 가문명 표기 보정 v1

일반 가문은 `다케다 가문`으로 표시되지만, 신세력 독립 등 동적으로 이름을
조합하는 경로에서는 `마츠다이라  세력`처럼 접미사와 공백이 달라지는 문제를
v0.94.1에서 보정한다.

원인은 두 가지가 겹친 것이다.

- PK `MSG_PK/JP/msgui.bin` ID 1139가 `%s 세력`으로 번역되어 있다. 순정 일본어
  서식은 `%s家`이며 여기서 `세력`은 원문 표현이 아니다.
- 성씨 문자열의 후행 ASCII 공백은 장수의 성·이름 조합에 쓰이므로 원본 데이터
  쪽에서 지우면 안 된다. 같은 인자가 세력명 서식으로 들어오면 그 공백과 서식의
  공백이 겹친다.

따라서 리소스 ID 1139만 `%s 가문`으로 바꾸고, 실행 파일의 공통 UTF-16 서식
함수에서 이 정확한 서식 포인터를 처리할 때만 첫 번째 인자 끝의 U+0020을
제거한다. 탭·전각 공백·문자열 내부 공백과 성씨 원본 데이터는 수정하지 않는다.
공백이 없는 등록 무장·사용자 입력 이름도 그대로 `이름 가문`으로 출력된다.

정적 패치는 PC 가로형, PC 가로형 XInput, PC 세로형, PC 세로형 XInput,
Steam Deck의 다섯 배포 변형에 동일한 의미로 적용된다. 패처는 알려진 v0.94.0
대상 해시와 명령 바이트가 정확히 일치할 때만 후킹하며, 이미 적용된 대상은
멱등 처리하고 다른 바이트는 거부한다.

2026-08-20 실제 Steam JP PK 1.1.7 설치본에서 기존 v0.94.0 관리 설치를
검증된 백업으로 복구한 뒤, B `그리운 경찰감성체` 리소스와 PC 가로형 XInput,
Steam Deck 정적 패치를 적용했다. 세 번들 모두 `already_applied: true`와 보고
버전 `0.94.1`을 확인했고, 실제 EXE 세 개와 `msgui.bin`의 SHA-256도
`validation.v1.json`의 고정값과 일치했다. 게임을 완전히 종료한 상태에서
Steam 런처로 새 프로세스를 실행해 2560×1600 타이틀과 한국어 메인 메뉴,
214초 이상 응답 상태와 크래시 이벤트 0건을 확인했다. 저장 데이터의 독립
신세력 상단 UI 표기 QA는 별도 확인 항목으로 남는다.
