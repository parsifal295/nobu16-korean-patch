# 이슈 124 지명 전체 독음 보정 v2

공유 테이블 회귀 판정과 이전 후보 철회 내역은
`SHARED_STRDATA_REGRESSION_AUDIT_KO.md`에 기록한다.

## 결론

성 주변 지역명 표에는 지명이 아닌 일반 단어·문장 번역과 잘못된 독음이 섞여 있다.
이 문제는 실행 코드가 아니라 지역명 전용 `MSG_PK/JP/msgdata.bin`의 한글 문자열을
고쳐 해결한다. 이전 대사 전수 번역과 좌표를 공유하는 `MSG/JP/strdata.bin`은
안전 기준 해시만 검사하고 절대 출력하거나 수정하지 않는다.

표시 ID `9947..11960`과 읽기 ID `11961..13974`의 2,014쌍을 모두 검사했다.

- 공용 항로 라벨 720쌍: 지명이 아니므로 원문 분류만 확인하고 그대로 보존
- 실제 지명 1,294쌍: 전부 동일한 독음 생성 규칙의 적용 대상
- 영어 로마자와 일본어 가나가 일치하는 지명: 1,293쌍
- 영어 로마자 단어 경계가 있는 복합 지명: 88쌍
- 영어와 일본어 독음이 다른 예외: ID 10388 한 건. 일본어 가나를 우선해 `오지야`로 확정

1,294쌍 모두에서 일본어 가나로 한글 표기를 다시 만들고 표시명과 읽기 칸에 같은
검증 결과를 적용한다. 이 중 988쌍은 기존 표기가 이미 맞아 바이트가 유지되며,
306쌍에서 실제 변경이 발생한다. 변경 문자열은 표시명 240개와 읽기 108개,
합계 348개다.

## 독음 생성 규칙

1. 영어판 읽기는 공용 라벨과 실제 지명을 구분하고 복합 지명의 단어 경계를 찾는 데만 쓴다.
2. 실제 한글 독음은 일본어판 가나 읽기를 기준으로 만든다.
3. 복합 지명은 영어 단어별 로마자 모라와 일본어 가나 모라가 유일하게 대응할 때만 분리한다.
4. 각 단어의 첫 `k/t` 계열과 단어 중간 표기를 구분하며, 촉음·발음·장음을 함께 처리한다.
5. 이 프로젝트의 기존 지명 표기에 맞춰 `つ(tsu)`는 `쓰`로 적는다.
6. 기존 문자열의 선행·후행 공백은 구조 정보일 수 있으므로 그대로 보존한다.
7. 모든 실제 지명은 표시명과 읽기 칸을 같은 결과로 맞춘다.

예를 들면 `나카자토/나카사토`는 `나카사토`, `시모우사카이조` 계열은
`시모사 가이조`, 일반 단어로 번역된 `봉화`는 지명 독음 `노로시`, `축성`은
`쓰이키`, `가문 대리`는 `에시로`로 정리된다.

## 빌드 안전 계약

`issue_124_region_names.policy.v2.json`은 상용 원문을 싣지 않고 범위, 판별 결과,
예외 소스 해시, 전체 결과 벡터 해시만 고정한다. 빌더는 다음 조건을 모두 강제한다.

1. 입력 후보와 일본어·영어 참조 파일의 크기 및 해시가 정확히 일치해야 한다.
2. 전체 2,014쌍, 실제 지명 1,294쌍, 공용 라벨 720쌍의 ID 집합을 재검증한다.
3. 일본어와 영어 모라 일치 1,293쌍, 고정 예외 한 건, 복합 지명 88쌍을 재검증한다.
4. 1,294개 전체 한글 결과 벡터와 실제 변경 좌표 벡터를 고정한다.
5. 승인 범위 밖 `msgdata` 문자열은 바꾸지 않는다.
6. 공유 `strdata`는 안전 기준 해시를 확인하되 출력하지 않는다.
7. 출력 후보의 압축 전·후 크기와 해시를 고정한다.
8. 입력 폴더나 Steam 설치 폴더로 출력하려 하면 거부한다.

```powershell
python workstreams/issue_124_region_names_v1/build_issue_124_region_names_v1.py `
  --input-root <pinned input root> `
  --jp-reference-root <Steam 1.1.7 Japanese stock root> `
  --en-reference-msgdata <pinned English msgdata.bin> `
  --output-root <empty scratch output>

python -m unittest tests/test_issue_124_region_names_v1.py
```

출력에는 수정된 `MSG_PK/JP/msgdata.bin` 하나, 전체 2,014쌍의 소스 비포함 감사표,
검증 보고서만 생긴다. 빌더 자체는 Steam 설치본을 수정하지 않는다.
