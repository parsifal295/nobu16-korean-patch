# 이슈 115 — 지행 호출 화면 이름 열 간격

## 재현 결과

지행 `호출` 화면은 800px 폭의 좌·우 인물 목록 패널을 사용한다. 실제 화면에서
좌·우 `군사` 탭의 긴 인물명이 `전법` 열로 넘어갔고, `특성` 탭에서도 같은 형태로
`특성 1` 열을 침범하는 것을 확인했다.

대응 PARAM은 다음 두 파일이다.

- 좌패널: `PARAM_PK/Person_Tenpou_Call_LeftInfo.bin`
- 우패널: `PARAM_PK/Person_Tenpou_Call_RightInfo.bin`

## 폭 계산 기록

사용 가능 총폭은 모든 프로필에서 800px이다. 현재 열 합계의 남는 폭만 사용하며,
다른 열을 줄여야 하는 프로필은 변경하지 않았다.

### 좌패널

| 그룹 | 현재 이름 폭 | 현재 합계 | 여유 폭 | 목표 이름 폭 | 최종 합계 |
|---|---:|---:|---:|---:|---:|
| `0120` | 188 | 704 | 96 | 272 | 788 |
| `0038` | 188 | 700 | 100 | 272 | 784 |
| `0122` | 188 | 602 | 198 | 300 | 714 |
| `1210` | 188 | 784 | 16 | 변경 없음 | 784 |
| `0482` | 188 | 632 | 168 | 300 | 744 |

### 우패널

| 그룹 | 현재 이름 폭 | 현재 합계 | 여유 폭 | 목표 이름 폭 | 최종 합계 |
|---|---:|---:|---:|---:|---:|
| `0120` | 216 | 748 | 52 | 변경 없음 | 748 |
| `0122` | 216 | 800 | 0 | 변경 없음 | 800 |
| `2248` | 188 | 500 | 300 | 300 | 612 |
| `0712` | 188 | 584 | 216 | 300 | 696 |
| `0482` | 216 | 612 | 188 | 300 | 696 |
| `1210` | 216 | 750 | 50 | 변경 없음 | 750 |
| `2098` | 216 | 724 | 76 | 272 | 780 |
| `1138` | 216 | 800 | 0 | 변경 없음 | 800 |

`군사`는 우패널 그룹 `0712`, `특성`은 그룹 `0482`를 사용하므로 각각 이름 폭이
300px로 늘어난다. 기본·행동·영지처럼 272px에도 못 미치는 프로필은 기존 열을
축소하지 않고 원래 폭을 유지한다.

## 적용 방식

`Set-TenpouCallPersonWidths.ps1`은 원본 크기·레코드 수·SHA-256·필드 타입을 모두
검증한 뒤 이름 필드만 변경한다. 변경 후에는 모든 그룹 합계가 800px 이하인지와
완성 파일 SHA-256을 다시 검증한다.
