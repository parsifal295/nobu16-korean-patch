# 군평정 아틀라스 일본어 잔여 0개 확장 계획

## 목표

군평정 고·저해상도 아틀라스에서 일본어 UI 이미지 픽셀이 남을 수 있는
7개 그룹을 전부 한글 이미지로 교체한다.

1. 군평정 제목
2. 승리
3. 패배
4. 아무 버튼이나 누르십시오.
5. 전공 1위
6. 전공 2위
7. 전공 3위

기존 저해상도 한글 오버레이는 일본어 제목 상단과 버튼 안내 오른쪽을
완전히 지우지 못했으므로 최종 배치 기준으로 사용하지 않는다. Steam JP
1.1.7 순정 저해상도 `/12/0`에서 위 7개 일본어 영역을 모두 비운 뒤,
검수된 고해상도 한글 요소를 각각 축소·배치한다.

## 입력

| 역할 | SHA-256 |

| 현재 고해상도 통합본 | `E2B22DFD399E87DF109947F0F98FC58D1BF360B1B54299A6BB4D2051CE53EEA5` |
| 순정 고해상도 좌표 기준 | `00E9C1063ED164402AA70CB770100D8AE11A92B8024F20A4F1D89F2EA1A467F7` |

최종 저해상도 후보는 현재 통합본의 `/12` payload만 재구성한다. `/12`
밖의 outer는 현재 통합본과 byte-identical하게 보존한다.

## 저해상도 전체 교체 매핑

사각형은 `[left,top,right,bottom]`이다. 한글 목표 크기는 고해상도 소스
크기의 정확한 1/2 반올림이다.

| 그룹 | 고해상도 한글 소스 | 순정 저해상도 일본어 bbox | 저해상도 clear | 한글 목표 |
| --- | --- | --- | --- | --- |
| 군평정 | `[56,317,1145,720]` | `[5,121,629,410]` | `[4,120,632,412]` | `[44,163,589,365]` |
| 승리 | `[2603,399,2946,578]` | `[645,400,835,503]` | `[640,396,840,508]` | `[654,406,826,496]` |
| 패배 | `[2147,404,2492,576]` | `[1843,332,2038,434]` | `[1840,328,2040,436]` | `[1855,339,2028,425]` |
| 버튼 안내 | `[1385,774,2127,826]` | `[1081,209,1530,242]` | `[1080,208,1532,244]` | `[1121,213,1492,239]` |
| 전공 1위 | `[2960,400,3344,480]` | `[1082,254,1274,294]` | 같은 bbox | 같은 bbox |
| 전공 2위 | `[2982,500,3322,572]` | `[1297,256,1467,292]` | 같은 bbox | 같은 bbox |
| 전공 3위 | `[3686,644,4026,716]` | `[1501,256,1671,292]` | 같은 bbox | 같은 bbox |

패배 clear는 우측 패턴 바가 끝나는 `x=1832`보다 오른쪽에서 시작하므로
패턴 바를 지우지 않는다. 승리 clear는 인접 파란 sprite가 시작되는
`x=849`보다 왼쪽에서 끝난다. 버튼 안내 clear는 우측의 빨간 버튼 sprite가
시작되는 `x=1540`보다 왼쪽에서 끝나므로 버튼을 지우지 않는다.

## 고해상도 감사

현재 고해상도 한글 합성 경로는 다음 영역을 먼저 완전히 비운 뒤 한글
이미지를 넣었다.

| 일본어 그룹 | 전체 clear 영역 |
| --- | --- |
| 군평정 | `[0,288,1264,944]` |
| 승리·패배 | `[2080,350,2968,620]` |
| 버튼 안내 | `[1264,760,2600,900]` |
| 전공 배지 3개 | 각 소스·순정 목표 합집합 |

순정 고해상도의 대응 일본어 bbox가 모두 위 clear 영역 안에 있음을
확인한다. 전공 배지는 `build_002`에서 순정 native 위치로 복원된 결과를
사용한다. 최종 고해상도 후보는 `build_002`와 byte-identical하게 유지한다.

## 일본어 잔여 0개 검증

1. 기존 매핑의 `SAFE_MAPPINGS` 4개와 `AUDIT_ONLY_MAPPINGS` 3개를 합친
   7개가 일본어 이미지 전체 인벤토리와 일치해야 한다.
2. 순정 저해상도에서 알파 임계값 1로 각 일본어 bbox의 그림자·fringe까지
   포함한 픽셀 수가 0보다 커야 한다.
3. 각 일본어 bbox는 대응 clear 영역 안에 완전히 포함되어야 한다.
4. clear 직후 7개 clear 영역의 알파는 0이어야 한다.
5. clear 뒤에는 검수된 고해상도 한글 RGBA만 붙인다.
6. 일본어 bbox 밖의 비대상 BC3 block은 순정 저해상도와 byte-identical하게
   보존한다.
7. 한글 target 밖이면서 일본어 clear 안인 부분에는 알파 임계값 1에서도
   픽셀이 없어야 한다.
8. 전체 저해상도 atlas PNG와 7행 before/after contact sheet를 직접
   시각 검수한다.
9. 고해상도는 기존 잔여 제거 영역과 순정 일본어 bbox의 포함 관계 및
   전체 atlas PNG를 다시 검수한다.

## 구조·배포 게이트

- 고해상도 변경 outer는 `/17`, 저해상도 변경 outer는 `/12`로 제한한다.
- resource id `58`, G1T platform `0x0A`, BC3 `0x5B`, texture 수와 크기를
  유지한다.
- LINK/LZ4/G1T round-trip과 후보 독립 재검증을 통과해야 한다.
- 후보는 ignored `tmp/battle_merit_badges_native_repair_v1/build_005`
  아래에만 생성한다.
- Steam, 릴리스, Git 커밋·푸시는 변경하지 않는다.

## 사전 검수 결과

`PASS`

## build_003 시각 검수에 따른 강화

초기 `build_003`은 알파 임계값 32 검사에서는 7개 그룹 모두 통과했지만,
전체 atlas 시각 검수에서 군평정 아래의 저알파 일본어 그림자 픽셀이
확인되어 최종 후보에서 제외했다. 위 좌표와 검증 기준은 알파 임계값 1로
확장한 최종 `build_005` 기준이다.
